# Bus Reservation System

A simple Bus Reservation System built using C++, MySQL, HTML, CSS and JavaScript.

## Features

- View available buses
- Book a bus ticket
- Check seat availability
- Prevent duplicate seat booking
- Cancel booked tickets
- Store booking information in SQLite database
- Simple web-based user interface
- C++ backend for handling reservations

## Technologies Used

- C++
- OOP
- MySQL
- HTML
- CSS
- JavaScript
